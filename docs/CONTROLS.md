# 操作指南

[返回项目首页](../README.md)

进入场景后，直接使用键盘或顶部工具栏操作。点击右上角「？」也能查看页面内的帮助。

## 骑行与互动

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车 |
| `A` / `←` | 向左变道 |
| `D` / `→` | 向右变道 |
| `Q` | 降挡 |
| `E` | 升挡 |
| `Space` | 跳跃 |
| `T` | 放手展翅并抬起前轮 |
| `B` | 按车铃 |
| `H` | 鹈鹕大叫 |

左右变道可以追鱼，金色的鱼值 5 分。参数面板中可以调整巡航速度、自动驾驶和自动变速；启用自动驾驶后，几秒不操作就会自动去追鱼。

鼠标也能触发场景互动：点击鹈鹕会发出叫声，点击车铃或自行车会响铃，点击远处海面会有鱼跃出。

触屏设备提供方向按钮、车铃、特技与跳跃按钮。

## 镜头

按 `C` 依次切换镜头，或点击顶部的镜头名称：

| 镜头 | 适合观看的内容 |
| --- | --- |
| 自由环绕 | 自己选择方向和距离，观察角色与车辆 |
| 追随 | 跟着鹈鹕向前骑行 |
| 侧面跟拍 | 观看踩踏、车轮和特技动作 |
| 电影运镜 | 让镜头自动运动，欣赏沿途风景 |
| 鹈鹕视角 | 从骑行者的位置看向前方 |

拖动鼠标旋转视角，滚动滚轮缩放。在其他镜头中拖动场景，会切换到自由环绕。

## 时间、声音与界面

| 按键 | 作用 |
| --- | --- |
| `N` | 当前时间快进 3 小时 |
| `M` | 切换背景音乐开关 |
| `P` | 暂停 / 继续骑行 |
| `U` | 隐藏 / 显示界面 |
| `K` | 下载当前画面的 PNG 截图 |
| `F` | 进入 / 退出全屏 |

时间滑块可以直接选择一天中的时刻，旁边的时间流动按钮控制昼夜是否继续变化。**停止时间流动只固定场景时刻；暂停骑行使用 `P`。**

「静音进入」适合先看画面。`M` 控制背景音乐，整体音量和音乐音量分别在参数面板的「声音」中调整。浏览器音频需要用户点击或按键后才能启动。

## 参数面板

点击右上角 ⚙️ 打开或收起面板。

| 分类 | 可调整内容 |
| --- | --- |
| 骑行 | 巡航速度、自动驾驶、自动变速 |
| 时间与天气 | 时刻、时间流动与流速、云量、浪高、雾浓度 |
| 画面 | 画质、泛光及强度、曝光、帧率显示 |
| 鹈鹕 | 头盔、墨镜、围巾、目光跟随鼠标 |
| 声音 | 主音量、生成式音乐开关、音乐音量 |

想让画面更流畅，可先降低画质，再尝试关闭泛光。截图前可选择镜头和时间，用 `U` 收起界面；按 `K` 后，浏览器会下载以 `pelican-ride-` 开头的 PNG 文件。

## 分享当前风景

点击顶部 🔗 会复制包含当前时间和镜头的链接。其他人打开已部署的网站链接时，会进入相应的时刻与镜头；它不保存整段骑行进度。

此功能适合在 HTTPS 网站上使用。若页面通过本地文件打开，请分享已部署的页面地址，而不是本机 `file://` 链接。
